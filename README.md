# GeorgeTech Holdings — Next.js Starter

This is a minimal Next.js + TypeScript + Tailwind starter scaffold implementing the GeorgeTech Holdings (Pvt) Ltd storefront and Vehicle Importation page.

Quick start:

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```

Open http://localhost:3000

This scaffold includes placeholder images and sample product data in `data/products.ts`.
